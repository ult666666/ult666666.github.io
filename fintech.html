Comparing financing plans for a frontier AI lab

Capital Strategy Studio compares hypothetical funding rounds for a frontier AI lab: how much each one raises, how much of their stake existing holders keep, and how each plan holds up under bear, base and bull cases.

Try Capital Strategy StudioRead the case study

Frontier AI Valuation Lab

The studio is part of a valuation model I built. It values Anthropic and OpenAI with a discounted cash flow model under bear, base and bull cases, and a Monte Carlo panel shows the spread of value around each case. The browser and a Node.js API run the same math, and separate Python scripts recompute it.

Four steps through one decision

1. Define the goals

Set a capital objective and the share of starting ownership to keep, then enter each plan’s price and size. Goals that conflict leave no eligible plan, and the studio says so.

2. Compare the plans

See each plan against both goals on a chart and in an equivalent table, with any capital shortfall and the ownership each plan keeps.

3. Challenge the ranking

Run every plan through named operating cases and shorter valuation horizons, and find the break-even equity values where the ranking flips.

4. Record the decision

Choose a plan, explain the trade-off, name what you still need to know and set a review trigger. A share link or a JSON record reopens the inputs as entered.

The same model also has Value Horizon, Thesis Lab, Ownership Frontier and a Research Casebook. The worked decision is also a PDF.

Code and docs

Each part of the decision has its method written down and a separate check.

Full list in the case study
  • The capital method keeps operating value, equity value, the round price and ownership apart, and counts the proceeds as cash once.
  • An independent Python reference recomputes break-even values, regret, dominance and price intervals.
  • The architecture shares one set of calculations between the browser and a bounded Node.js API, and a revision check stops a late response from confirming an edited decision.
  • The worked decision brief keeps the analyst’s choice separate from the computed ranking, next to the goals, the alternatives, the reasoning and a review trigger.

Limits

  • The company figures rest on illustrative assumptions and incomplete public disclosures. They are not valuations of Anthropic or OpenAI or investment advice, and the project is not affiliated with either company.
  • The studio compares plans you enter against goals you set. It does not estimate how much a company needs to raise, and scenario counts are not probabilities.
  • The round model keeps the proceeds as cash and leaves out fees, preferences, option pools, secondary sales and later rounds.
  • The comparison metric is a modeled allocation that can be negative. It is not an investment return or a share price.
