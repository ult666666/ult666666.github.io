01 BACKEND RELIABILITY

RelayBox

A webhook arrived twice. The worker disappeared. Now what?

A signed webhook inbox with a durable SQLite job lifecycle. Delivery IDs deduplicate matching payloads, conflicting reuses are rejected, and expiring leases let a new worker recover interrupted work.

The detail to inspect: a fencing token prevents an old worker from acknowledging a job after another worker has reclaimed it.

At-least-once work requires idempotent handlers. A durable inbox cannot make an external side effect happen exactly once.

From a RelayBox checkout with Python 3.11+, run this focused test. It uses a temporary database and a controlled clock.

Expected: one passing test. Worker B reclaims an expired lease; worker A's old token cannot acknowledge it.

Follow the decision

Read claim and _complete together. The SQLite write transaction selects one owner, while the current token and expiry guard completion.

A process can still finish an external side effect after losing its lease. The consumer must make that effect idempotent; this database cannot roll it back.

02 REPRODUCIBLE AI EVALUATION

TraceBench

A new answer sounds better. Did the contract get worse?

An offline evaluation toolkit for recorded model outputs. Explicit exact, contains and JSON-subset checks turn English and Mandarin fixtures into reproducible results. Baseline comparisons identify which cases regressed.

Measured latency and explicitly supplied token pricing remain separate from correctness. No provider keys or model calls are needed to reproduce the examples.

03 FULL-STACK / OPERATIONS ANALYTICS

Impact Ledger

One participant. Three visits. Two very different numbers.

A nonprofit reporting workbench with a typed frontend, a Python API and a SQLite store. Filter synthetic program records, distinguish unique participants from attendance, and compare session spending with budget.

Sessions and attendance have separate grains, so a busy event does not multiply its own expenses. Imports validate before committing, and accessible tables keep the numbers available alongside the charts.
