Case study: research system

Agentic Trading Research

A research-only system for short-term stock research. Language models gather evidence and propose ideas, and plain Python checks decide what passes. It cannot place orders.

The problem

A model-written market thesis can sound convincing while it rests on stale prices, weak sources or risk assumptions that do not fit together. The hard part is keeping a persuasive story from turning into permission to trade.

How it works

Proposals from the models pass through deterministic Python checks for source freshness, provenance, risk limits and decision rules. Every claim needs a source, and a check that cannot pass returns HOLD with machine-readable reasons instead of a guess.

Broker access is read-only and order tools are blocked, so a person places any real order by hand. The public repository includes a small runnable gate with six synthetic scenarios: one reaches human review and five return HOLD.

Checking a backtest for overfitting

Try enough strategies and the best one looks skilled by chance. A standard-library package in the examples applies four checks that quant reviewers use: the probabilistic and deflated Sharpe ratios (PSR and DSR), the probability of backtest overfitting (PBO), and White’s Reality Check with Hansen’s SPA test.

In the demo, the best of 100 no-skill strategies has a naive PSR of 0.9989, and all four checks flag it. A strategy with injected skill passes all four.

The tests reproduce the numerical example in Bailey and López de Prado’s DSR paper, compare PBO with a brute-force version, and show that each of nine planted bugs makes a test fail.

Try it

The examples need Python 3.11 or newer and only the standard library. Run examples/overfitting_demo.py for the diagnostics, or examples/fail_closed_gate.py --all for the six gate scenarios. Neither touches the network.

Limits

  • The repository is a curated snapshot for reading. Many modules import private code and do not run here; the examples do.
  • There is no automated order execution, and nothing here is investment advice or evidence of profit.
  • The diagnostics demo uses independent Student-t returns without trading costs.

I built the system with AI coding assistants, and its research pipeline calls language models.
