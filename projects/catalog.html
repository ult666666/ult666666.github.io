Frontier AI Valuation Lab

A valuation and financing model for frontier AI labs that compares funding plans against a capital goal and an ownership floor, with a seeded Monte Carlo range for value.

  • JavaScript
  • Node.js
  • Python
Try
Open the worked decision and raise the ownership floor from 88% to 90%: only Plan A still qualifies. Then open the Monte Carlo panel and look at the median and the spread of value around the Anthropic Base case.
Where to look
The financial math is plain JavaScript shared by the browser and a Node.js API, which return byte-identical JSON for the same Monte Carlo request. Separate Python scripts recompute the capital and uncertainty arithmetic.
Limits
Illustrative assumptions and incomplete public data, with no affiliation to the companies named. Simulated percentiles describe the ranges entered, not a forecast.

crossbook

An order-matching engine in Rust with call auctions, crash recovery, a market-data feed and multi-instrument sharding, checked against a second, simpler engine.

  • Rust
  • WebAssembly
  • proptest
Try
Run the auction demo. An opening call collects orders without trading, prints the indicative uncross after each one and rejects an immediate-or-cancel order. The uncross then fills 13 lots at 101, market orders first.
Where to look
Start with the one-pass clearing-price search, then the brute-force uncross that tries every price. The two agree on 20,000 random books, including ties at each rule.
Limits
Books live in memory in one process, journals are written without fsync, and there is no network gateway or market connection. The clearing price is always one of the orders’ limits, and there are no volatility interruptions.

Run it locally

cargo run --release -p crossbook-cli -- demo
cargo run --release -p crossbook-cli -- auction
cargo run --release -p crossbook-cli -- verify --orders 1000000

LineageGuard Studio

Reviews a database schema change against the lineage it affects, with evidence from fixtures, DataHub or a dbt manifest, and resumes a run that crashed.

  • Node.js
  • SQLite
  • JavaScript
Try
Review a column rename against a dbt manifest from a synthetic project. Renaming fct_mrr.mrr_usd lists five downstream models and two exposures with their owners. The decision stays at needs-evidence, because a manifest cannot show usage.
Where to look
Start with the manifest adapter, which refuses unknown versions, cycles and graphs whose edge lists disagree. A seeded property test compares its lineage with an independent walk of depends_on.
Limits
Synthetic data, and the optional DataHub capture is read-only. Lineage from a manifest is model-level, so it can block a change or ask for more evidence but never clear one. A passing export check means internal consistency, not approval.

Run it locally

npm run studio:review -- --dbt-manifest=public/studio/dbt/saas-analytics-warehouse/manifest.json --dbt-catalog=public/studio/dbt/saas-analytics-warehouse/catalog.json --request=examples/dbt/rename-mrr-usd.json --output=./.lineageguard/dbt-review.json
npm run studio:benchmark -- --check
# Use new export paths when repeating; existing outputs are never overwritten.

RelayBox

A durable webhook inbox that deduplicates deliveries and fences stale workers, plus outbound delivery signed per the Standard Webhooks specification.

  • Python
  • SQLite
  • HMAC
Try
Deliver a message to the example receiver. The first attempt gets 503 with Retry-After, and the retry succeeds with the same webhook-id. The inbound demo sends one signed event twice and shows retries, leases and recovery.
Where to look
Start with the dispatcher: full-jitter backoff, the dead-letter queue and replay. Signing matches the specification’s published test vector, and a sender killed mid-request leaves its lease for another to resend.
Limits
A single-host SQLite service. Outbound targets are loopback-only unless you allow others, there is no rate limit or circuit breaker, and signing secrets are stored unencrypted.

Run it locally

python3 -m relaybox --db .local/demo.sqlite3 demo
python3 -m relaybox --db .local/demo.sqlite3 serve --demo-secret
# Outbound: start the receiver in one terminal, then deliver from another
python3 examples/receive_webhooks.py --demo-secret --fail-first 1
python3 -m relaybox --db .local/out.sqlite3 subscription add http://127.0.0.1:8788/hook --event-type example.created --demo-secret
python3 -m relaybox --db .local/out.sqlite3 publish example.created examples/payload.json
python3 -m relaybox --db .local/out.sqlite3 deliver --max-deliveries 10 --wait 15

quantkit

Option pricing, portfolio optimization, backtesting and VaR model validation, checked against textbook values and exact calculations.

  • Python
  • NumPy
  • SciPy
  • pandas
Try
Simulate fictional prices, forecast one-day 99% VaR each day, and backtest the forecasts with Kupiec’s and Christoffersen’s tests, the Basel traffic light and the Acerbi–Székely Z2 test.
Where to look
Start with the four rolling forecasters, then the dynamic program that gives each backtest its exact size. A perturbation test keeps every forecast blind to the return it is scored against.
Limits
Educational software on synthetic data, not investment advice. VaR covers one day and one return series, and the likelihood-ratio p-values are asymptotic.

Run it locally

uv sync
uv run quantkit simulate --output prices.csv
uv run quantkit var-backtest prices.csv --method ewma --level 0.99

powerlift

Experiment statistics: power analysis, A/B/n tests with Dunnett’s correction, CUPED, sequential monitoring and Bayesian tools.

  • Python
  • SciPy
  • statsmodels
Try
Read a seeded CSV with one control and three variants. The sample-ratio check runs across all four arms, and Dunnett’s test finds only variant D different while keeping the family-wise false-win rate at 5%.
Where to look
Start with the many-to-one analysis, where the shared control turns a k-dimensional integral into a two-dimensional one. Results agree with scipy.stats.dunnett.
Limits
Results depend on study design and data assumptions, and a significant result alone is not a business decision. Multi-arm comparisons are many-to-one and pool the arms’ variance.

Run it locally

uv sync
uv run python examples/multi_arm_simulation.py --csv arms.csv
uv run powerlift analyze --csv arms.csv --group-col arm --value-col revenue_usd --control-label A --treatment-label B --treatment-label C --treatment-label D

searchlite

A full-text search engine in TypeScript with compressed postings, top-k pruning that never changes a ranking, explainable scores and relevance evaluation.

  • TypeScript
  • BM25F
Try
Compare two saved indexes against your own relevance judgments in the browser and look for queries that got worse. Then run the pruning property tests, which compare pruned results with scoring every match.
Where to look
Start with the blocks of 128 documents, their score bounds and the MaxScore windows built on them. On 10,000 synthetic documents, pruning made median queries 7 to 15 times faster.
Limits
A small in-memory library with English-only analysis. Block-max WAND is not implemented, and one phrase-heavy query is slower with pruning.

ProofCast

Local media generation with provenance records, Ed25519 manifest signatures and a Merkle transparency log.

  • Python
  • Streamlit
  • SHA-256
Try
Generate a local bundle, then run the tamper demo. It signs and logs the bundle on copies and catches a changed media byte, a changed manifest, a different key, a flipped proof bit and a rewritten log entry.
Where to look
Start with the RFC 6962 and RFC 9162 Merkle tree and its inclusion and consistency proofs. They match 195 of 196 published transparency-dev/merkle vectors; the last one uses placeholder roots and is rejected on purpose.
Limits
A signature proves which key signed, not who holds it. The log is one local file without witnesses, the private key is stored unencrypted, and the optional B2 upload has not run against a real bucket.

JUST-QR

A small browser QR generator with its own ISO/IEC 18004 encoder and image export.

  • HTML
  • JavaScript
  • Canvas
Try
Make a QR code at the default level H, try a link that is too long, then lower the level until it fits and compare the clipboard and download images.
Where to look
Start with qr.js: Reed-Solomon coding with block interleaving, format and version information, and mask choice by the four penalty rules. Tests match the ISO and zxing vectors and decode random symbols with jsQR.
Limits
A QR code encodes what you type and does not check whether the link is safe. One segment per code, with no ECI, Kanji, Micro QR or structured append. The page requests two Google Fonts and must be served over HTTP.

Run it locally

python3 -m http.server 8000

npx playwright install chromium --only-shell
