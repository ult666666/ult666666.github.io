Case study: website

MOTIONX

The website for MOTIONX, the motion-design studio I run, built with Next.js and TypeScript. The same repository holds a Python tool that drafts outreach emails and leaves sending to a person.

The site

MOTIONX makes product films and the websites around them, so the studio’s own site has to move without getting in the way of reading. The homepage is edited for a quick read, and the detail lives on separate pages.

The frontend

It uses the Next.js App Router, TypeScript and Tailwind CSS v4. All animation is CSS, with no animation library, and visitors who prefer reduced motion or save data get still posters instead of autoplaying video.

The contact form has no backend. It prepares the message and opens it in Gmail or the default mail app, and never claims that anything was sent. Playwright tests cover navigation, the contact flow, reduced motion and layouts down to 375 px wide.

The outreach tool

A separate Python tool researches a prospect and drafts one email. Every draft must pass a validator that returns PASS or FAIL with reasons, checking length, a single offer, links and regulated claims.

The drafting code cannot mark a prospect as contacted; sending is a separate step that a person takes. The public tests run on fictional companies on the reserved .example domain.

Limits

  • The films on the site are self-initiated concept work, not client commissions.
  • The outreach tool drafts email; it does not send any on its own.
  • The public repository is a curated snapshot of a private one.

I built both parts with AI coding assistants.
