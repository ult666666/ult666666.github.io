# Security and responsible disclosure

Report a suspected vulnerability privately through [GitHub's private reporting form](https://github.com/ult666666/ult666666.github.io/security/advisories/new).

Include the affected public URL or commit, reproduction steps using synthetic data, the expected result and the observed result. Do not attach live credentials, private financial records, account identifiers or unpublished trading-system material. Do not put sensitive findings in a public issue.

The portfolio is a static public site with no application accounts, payment processing or trading endpoint. The deployment builder publishes only reviewed paths and verifies the emitted bytes. See [the publication boundary and its limits](docs/PUBLICATION_BOUNDARY.md).

Please report findings in linked demos to their corresponding repository. Do not probe third-party systems or other users' data. Private reporting is not a promise of a response deadline, a bug bounty or immunity from applicable laws.

This document describes the intended process. Repository protections, account security and dependencies still require ongoing review; no website or scan can guarantee absolute security.
