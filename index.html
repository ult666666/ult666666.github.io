Frontier AI Valuation Lab

Suppose an AI lab wants to raise $25 billion. How much of the company can its current owners keep? I built a JavaScript model that lets you change both constraints. In the worked example, raising the ownership floor from 88% to 90% leaves just one financing plan. Separate Python calculations check the figures.

crossbook

When two buyers offer the same price, who gets the trade? I built a Rust engine that matches orders by price and arrival time, then checked it against a second, simpler engine. In the WebAssembly playground you can replay 100,000 commands and compare the results with the native build.

Replay the order bookCase studyCode

LineageGuard Studio

Renaming one database column can break a report several teams away. I built a Node.js tool for reviewing database schema changes. It follows the dependencies in a dbt manifest to identify the affected reports. The local version saves its findings in SQLite so an interrupted review can resume.

Review a schema changeCase studyCode

Luma Keys

A score tells you which notes to play. Choosing the next finger is a different problem. I built an offline Mac app that plans fingering across a piece and uses three.js to show both hands on the keys. You can follow a passage, then play it back on a MIDI keyboard.

MOTIONX

I founded MOTIONX, a motion-design studio, and built its website so visitors can see the work and get in touch. I used Next.js and TypeScript for the pages and CSS for the animation. A separate Python tool checks outreach drafts before I decide whether to send them.

About

I like a project with an answer I can check. When I wrote quantkit, I used an options example from John Hull’s textbook to check that my code priced the call at 4.76 and the put at 0.81. In powerlift I tested a tempting shortcut. Even when the two groups were identical, checking ten times and stopping at the first significant result produced a false win in 19.5% of simulations. The intended rate was 5%.

I write mostly Python, TypeScript and SQL. The tools I like best do one job well and say plainly what they don’t do.

If you’d rather read than click around, start with how the valuation math is checked, or with what LineageGuard refuses to approve.
